# Ghost Hands Mobile — THE EVERYTHING TRAIN

Authorized by Ryan, Oct 25, 2026 ~05:31 AM ET ("Everything"), covering all three
idea menus presented that morning. Built as a sequential release train: one
build at a time on the same tree, each release fully gated (host harness green,
foreground-verified APK facts, BUILD_NOTES section) before the next spawns.
Spikes (R3, R6, R13) may honestly fail; a failed spike reports evidence and the
train moves on. Site grants (R5) were flagged to Ryan as a governor-semantics
change before he said "Everything" — included on that basis.

Standing gates for every release: same package com.ghosthands.app, preserved
keystore (cert de6969f0…25cd71b), permissions unchanged unless the release's
brief names one, grammar default OFF until R3 resolves, all prior tests green,
new trail event types registered in Trail.EVENT_TYPES first, remote-storage
APK link delivered per release.

## The train

- **R1 — v3.9 FORMS FRONTIER PACK.** Perception + actions for select dropdowns
  (options carried in the map), radio groups, checkboxes, date/text inputs,
  multi-field forms grouped by form. New actions: choose, toggle. Submits stay
  consequential under the governor. Proving ground: httpbin.org/forms/post
  (pizza form) as host fixtures + scripted end-to-end; live run is Ryan's
  field test.
- **R2 — v3.10 PERCEPTION DELTAS + PLANNER STYLES.** Per-step map sends only
  changed elements (full map on arrival/mismatch), token savings proven in the
  harness. Planner styles Careful / Fast / Thorough (Settings > AGENT chips,
  default = today's posture): prompt posture + default step budget presets.
- **R3 — v3.11 GRAMMAR HUNT (spike -> fix).** Root-cause the contained native
  crash that keeps grammar OFF. Deliverable: root cause + fix with grammar
  re-enabled behind its setting, OR an evidence report and containment stays.
- **R4 — v3.12 CLARIFY + RETRY.** Governed `ask` action: the planner can put a
  clarifying question to Ryan through the approval-style panel; the answer
  re-enters the run as user provenance. Strategy retry: a stuck run's card
  offers one-tap counter-setting retries (desktop mode, alt fallback engine,
  strict pack) chosen from the failure shape.
- **R5 — v3.13 TRUST PACK.** Resume interrupted runs (RunMarker + trail-based
  resume offer on launch). Governor self-check (Diagnostics: built-in
  injection-seeded local page, seatbelt pack must deny all, live verdict).
  Site grants (per-site remembered consequential approvals, revocable in
  Settings, recorded on every trail they touch).
- **R6 — v3.14 BEYOND THE BROWSER (spike).** Accessibility-service feasibility:
  read another app's node tree + dispatch a governed tap, behind a default-OFF
  experimental toggle and Ryan's own service enablement. Spike report decides
  any build.
- **R7 — v3.15 MULTI-TAB.** 2-3 WebView tabs, per-tab element maps and read
  state, tab actions for the planner, tabs visible in the browser stage.
  SHIPPED Oct 25, 2026 (see status log).
- **R8 — v3.16 DOWNLOADS, DOCUMENTS, PAGE WATCH.** Governed downloads; read
  text/CSV/HTML files (PDF best-effort, limits stated). Watch-this-page:
  URL-based watches with text-diff verdicts alongside goal watches.
- **R9 — v3.17 CHAINING + SMART CHECKS + BRIEFING.** Goal chaining (one goal's
  findings seed the next; one combined card). Condition-aware watched checks
  (defer until charging and/or Wi-Fi, setting-gated). Morning briefing: spoken
  digest of overnight verdicts on first open.
- **R10 — v3.18 SEEING THE WORK.** Mission board drawer screen (watched goals,
  verdicts, streaks, next checks). Run-compare viewer (two runs side by side).
  Ask-about-a-run (questions answered from the trail by the on-device model).
- **R11 — v3.19 GLUE.** Run reports (shareable HTML export from trail + shots).
  Templates shelf (fare watch, forecast, restock, headlines). Share-sheet
  intake (text/URL into a goal or a page watch). Quick Settings tile +
  clipboard goal start.
- **R12 — v3.20 WIDGET + VOICE LOOP.** Home-screen widget (watched verdicts,
  live run status, Stop). Voice conversation loop (answer spoken, recognizer
  reopens for a follow-up goal that continues the session).
- **R13 — UNATTENDED CHECKS (spike).** Can a watched check truly run with the
  app backgrounded under Android 15 doze (foreground service + wake locks,
  readonly-forced, full trail, morning card)? Evidence report; any build is a
  separate release after Ryan sees the spike.

- **R14 — THE COMPARISON (capstone, Ryan's ask Oct 25, 2026).** After R1-R13
  land: a sourced, live-checked comparison of Ghost Hands Mobile against the
  real competitive set — Google Gemini on Android, Apple Intelligence / Siri,
  Samsung Bixby + Galaxy AI, the automation incumbents (Apple Shortcuts,
  Samsung Routines, Tasker), and the open-source / research phone agents
  (AppAgent, Mobile-Agent). Same axes for all: where the brain runs (device
  vs cloud), offline ability, browser-only vs phone-wide reach, governance
  (approvals, deny rules, audit trail), scheduling/watching, price, and who
  holds the keys. Verified against primary sources at comparison time, gaps
  stated as gaps — including ours. Deliverable: the matrix + a short verdict
  Ryan can publish.
